# Turnover!

## Agent skills

### Issue tracker

Issues live as GitHub issues in `lukegothic/Turnover-`, managed via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Device testing

A local build cannot update the Play install, and reaching a match state doesn't need waiting on the clock. See `docs/agents/device-testing.md`.

### Contributing

Read-only access to `lukegothic/Turnover-`: work through a personal fork (branch → push to fork → PR), never commit directly on `main`. See `docs/agents/contributing.md`.
